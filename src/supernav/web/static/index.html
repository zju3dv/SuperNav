GET CONNECTED

Bring your agent into view.

Use the same live directory for the viewer and the Habitat bridge. Set it before starting your usual experiment.

export SUPERNAV_LIVE_DIR="$PWD/data/nav_artifacts/live"
supernav-web

In the terminal that starts your bridge or experiment, export that same absolute path. Then run your usual supernav-run command. New sessions appear automatically.

For a tour without a simulator:

supernav-web --demo

Pause freezes this browser view. The agent keeps running. A remote server can be viewed through SSH port forwarding on port 8765.
