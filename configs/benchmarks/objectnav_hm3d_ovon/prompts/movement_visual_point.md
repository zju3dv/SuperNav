- hab_visual_point_navigate(view="front", point=[0.5,0.8]) - the ONLY translation tool in this arm: mark a normalized point on the latest front/right/back/left view and the bridge back-projects it through depth, snaps it to the nearest reachable navmesh point, and a greedy navmesh follower walks there. Each call executes immediately - no preview/confirm round-trip, no confirm_token, no per-hop step cap, and no geodesic distance cap. The mark is not restricted to floor: object bodies, walls, doorframes, and doorway openings are all legal marks as long as they are visible and have depth. How to pick points, read statuses, and recover from failures is documented in the localnav-pointnav-geo-based-executor skill - follow it. If a call ever returns preview_ready, the deployment is not running the gated configuration: inspect the overlay_image and re-call with the returned confirm_token to execute.
- Arm constraints: hab_local_navigate, hab_localnav_status, hab_localnav_stop, hab_forward, hab_backward, hab_visual_local_navigate, hab_visual_overlay_navigate, and hab_navigate_wam are not available here. All translation goes through hab_visual_point_navigate; hab_turn only rotates in place; hab_panorama only re-captures the surround.
