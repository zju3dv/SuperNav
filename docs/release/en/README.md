# SuperNav Documentation

Start with the [project README](../../../README.md) for installation, the overview
video, and a first episode. These guides describe the code and its current
execution requirements.

| Guide | What it covers |
| --- | --- |
| [Configuration](configuration.md) | Recipes, agents, models, local deployment, task composition, and overrides |

| [HM3D v2 and OVON](hm3d-and-ovon.md) | Scene and episode data, task preparation, navigation, and offline scoring |

| [Tool authoring](tool-authoring-guide.md) | Tool schemas, registration, dispatch, state, and validation |

Every guide has an English and Simplified Chinese version, with a language switch
at the top. Commands, configuration keys, and data formats are the same in both.
Task prompts and navigation Skills are executable experiment inputs and retain
their original language and contents.

Videos and research results are available on the
[project page](https://zju3dv.github.io/SuperNav/).
